# Hackathon Compliance Checklist

The First Commit rules state that project work must start when the hackathon opens, the repository must be public, AWS usage must be shown in the demo, AI coding tools must be disclosed, and third-party code/assets must have compatible licensing/credit. See the official rules: https://www.wemakedevs.org/aws/first-commit/rules

- [ ] Project work performed during hackathon window
- [ ] Public GitHub repository
- [ ] AWS usage visible in demo
- [ ] AI coding tools listed in submission
- [ ] Third-party libraries/assets credited and licensed
- [ ] Demo ≤ 3 minutes
- [ ] Demo link works signed-out
- [ ] Writeup explains problem, build, AWS role
- [ ] Git history reflects actual hackathon development
- [ ] No secrets committed
