# Commit Strategy

Keep commits small, coherent, and milestone-oriented.

Suggested sequence:

1. `docs: establish system design baseline`
2. `chore: scaffold backend and frontend`
3. `feat(api): add domain models and repositories`
4. `feat(api): add customer asset and job endpoints`
5. `feat(ai): add structured intake workflow`
6. `feat(memory): add service history retrieval`
7. `feat(ui): add dispatcher dashboard`
8. `feat(ui): add technician workflow`
9. `feat(infra): add local AWS stack`
10. `feat(infra): deploy cloud MVP`
11. `test: add evaluation and integration coverage`
12. `docs: finalize hackathon submission package`

Do not squash the entire hackathon into one commit. The event rules explicitly say repository history must match the event dates.
